# 测试用例与结果

测试日期：2026年10月22日。环境：Windows、Node.js 22.17.0、MongoDB 8.2.12、MongoDB Node驱动6.21.0、Edge 155.0.4283.62。最终自动测试43项全部通过，无跳过；浏览器验收12项通过，未发现页面JavaScript异常。详细执行输出分别保存在 `test-results.tap` 和 `browser-results.json`。

## 自动测试复现

先按README启动MongoDB，再在项目目录执行 `npm.cmd ci` 和 `npm.cmd test`。测试器通过随机端口启动真实HTTP服务，API用例操作真实MongoDB，不使用内存替身。测试库名为 `survey_test_时间戳_进程号`，清理前严格检查库名前缀，不删除业务库。

测试样本为 `scripts/demo.js` 的5题问卷：role单选；tools多选；method单选；hours数字；comment文本。role=no跳到comment；tools包含ai跳到hours；hours>=8结束，否则依次继续。除明确标注可选场景外均为必答。

## 已知边界

没有进行持续高负载、跨进程崩溃恢复或公网渗透测试，不根据三人并发测试声称大规模承载能力。数据库重连测试验证已提交数据可读取，不等同于断电恢复测试。演示脚本中的3份回答是模拟样本。初轮接口测试因沙箱本地连接限制失败，调整执行环境后重跑43项全部通过，未把初轮失败计为通过。
