# 阶段二需求与验收对应

依据课程《大作业一第一阶段》《大作业一：需求变更》。在阶段一原项目上增量修改，保留账号、四题型、校验跳转、填写保存、权限、匿名与重复限制及统计。

| 新需求 | 对应实现与验收 |
| --- | --- |
| 保存常用题目与多问卷复用 | 独立题目族及不可变版本；两份问卷引用同一版本 |
| 分享给其他用户 | 按已注册用户名授权；接收者可引用，创建者仍可使用 |
| 修改不影响旧问卷 | 追加版本；发布快照固定；原回答仍按旧内容解释 |
| 历史、来源与恢复 | 版本列表、parentVersionId与restoredFromVersionId；恢复生成新版本 |
| 不同版本同时存在 | 可从任一版本建立分支；不同问卷明确选用不同版本 |
| 查看题目使用范围 | 题目详情反查本人问卷与所用版本；他人引用仅统计数量 |
| 题库管理与更新 | 创建、修改、删除题库，增删题目族；选用新旧版本均需显式操作 |
| 单题跨问卷统计 | 同版本跨本人问卷合并，不同版本分组；支持选项计数、文本、数字平均及频数 |

## 原有功能保留

保留原 `test/api.test.js` 与 `test/logic.test.js`，按原43项测试进行回归；题库接口和迁移另增测试。保留既有填题“返回暂存、改选后只删除确定不再经过的答案”的规则。

## 数据兼容

保留原users/sessions/surveys/responses四集合及既有字段。新增question_families/question_versions/banks。旧题按原问卷ID与局部题ID建立独立族，不因同名而合并；备份后补充来源字段，不改原答案值或去重规则。支持预览、重跑与中断续跑。
