# 基于 MongoDB 的问卷系统阶段一


这是一个可本地运行的问卷系统。用户可以注册登录、创建与发布问卷、设置题目校验和条件跳转，通过链接邀请登录用户填写，并查看实时统计。所有业务数据和会话均存储在真实 MongoDB 中。

## 快速启动

环境：先安装 Node.js 22 或以上和 MongoDB 8.x（已在8.2.12验证）。首次运行安装依赖需要联网。

从 GitHub 下载 ZIP 并解压，或将仓库克隆到本机。Windows 用户双击项目根目录的 `start.cmd`。脚本会安装依赖、复制配置、在本地27019端口启动 MongoDB，并启动网页服务。浏览器访问 **http://127.0.0.1:3000**。关闭时在启动窗口按 Ctrl+C；脚本只停止由它启动的 MongoDB 进程。

也可以在 PowerShell 中执行：

```powershell
Set-Location '解压后的survey-stage1目录'
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1
```

已有 MongoDB 服务或使用 Atlas 时，复制 `.env.example` 为 `.env`，填写自己的连接地址，然后执行：

```powershell
npm.cmd ci
npm.cmd start
```

`start-local.ps1` 是默认本地27019端口的便捷启动方式。配置外部数据库时请直接使用 `npm start`。数据库账号需要对项目库拥有创建集合、设置验证器和索引的权限。

## 演示与自测

服务启动后，另开终端进入项目目录：

```powershell
npm.cmd run seed
npm.cmd test
```

可选演示账号：`demo` / `Demo2026!`。`seed` 导入一份“校园学习体验调查”和3份模拟回答，重复执行不会再次插入同一演示问卷。模拟回答用于演示，不能当作真实调查样本。

示例填写链接：http://127.0.0.1:3000/survey/000000000000000000000001

自动测试创建独立的 `survey_test_时间戳_进程号` 数据库，完成后删除该测试库，不清空项目业务库。43项测试均使用 Node 内置测试器，其中18项API测试连接真实 MongoDB，另有25项逻辑测试。实际测试记录见 `docs/test-results.tap`；12项浏览器验收见 `docs/browser-results.json`。

## 操作路径

1. 注册或登录。首次使用可以点击“用示例问卷开始”，生成属于自己的草稿。
2. 编辑标题、截止时间、匿名和多次填写设置。添加题目、选项、校验限制、跳转规则。
3. 保存草稿并发布。复制填写链接；填写人须登录，问卷允许时可匿名提交。
4. 作答时逐题校验并跳转；返回保留原输入，改选后仅清理不再经过的答案，确认后提交。
5. 创建者在工作台查看统计。关闭问卷后保留原有数据和统计，停止接收新填写。

## 文件说明

| 文件或目录 | 内容 |
| --- | --- |
| `src/` | HTTP接口、账号会话、MongoDB验证器和索引、校验跳转及统计 |
| `public/` | 中文响应式网页，无前端构建步骤 |
| `test/` | 25项逻辑测试及18项真实数据库API测试 |
| `scripts/` | 可选演示数据及演示问卷定义 |
| `docs/DESIGN.md` | 系统、数据库、权限和关键逻辑设计 |
| `docs/API.md` | 全部接口、请求例子、错误码和状态约束 |
| `docs/TESTS.md` | 可复现的步骤、输入、期望输出与实际结果 |

## 配置

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `MONGODB_URI` | `mongodb://127.0.0.1:27019` | 数据库连接地址 |
| `MONGODB_DB` | `survey_stage1` | 项目数据库名 |
| `HOST` | `127.0.0.1` | 默认仅本机访问 |
| `PORT` | `3000` | HTTP端口 |
| `COOKIE_SECURE` | `false` | HTTPS部署时设为true |

数据库连接失败时确认 MongoDB 已启动且端口与配置一致；3000端口被占用时修改 `.env` 的 `PORT`。截止时间按编辑者本机时区录入，数据库使用BSON Date。发布后不能编辑题目或重新打开已关闭问卷，避免历史答案与题目不一致；草稿可自由编辑。

## 仓库内容与验证

本仓库包含前后端源码、MongoDB schema、配置示例、运行说明、接口说明、自动测试和执行记录。
43项自动测试及12项浏览器验收均通过，结果见 `docs/TESTS.md`、`docs/test-results.tap` 和 `docs/browser-results.json`。
测试数据和演示账号仅用于本地验证。运行依赖、数据库运行文件和本地私有配置不上传仓库。
